# Eclipse Animation - the ultimate roblox animator plugin
This repository contains the most recent version of Eclipse Animator.
I have uploaded this simply so more people can kickstart their animation career on Roblox without paying for a plugin. If it gets updated, I will put it here.

# HOW TO DOWNLOAD?
Quite simple. You must download the plugin [here](https://github.com/roblox-animator/Eclipse-Animator/releases#release-updates). There will be a RBXMX file. Go to Roblox Studio > Plugins (in the top bar) and go to the Plugins Folder. You will drag the Eclipse Animator RBXMX file to this folder. You are set to go from there on.

## And if you want to buy the plugin...
Well, you can buy the plugin [here](https://create.roblox.com/store/asset/86116556258301/Eclipse-Animator). Even if I'm just uploading this for free, it'd be great to buy the plugin if you have money to spare.
